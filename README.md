# 🎰 SlotMachine

A simple Python Slot Machine game that simulates spinning reels and checks winning combinations.  
This project was built for practice while learning Python basics and GitHub workflow.

## 🚀 Features
- Random reel generation using Python's `random` module
- Simple betting system (optional)
- Balance tracking (optional)
- Beginner-friendly code structure
